# Verse v0.2.0: Selected-Text Craft Workbench

A deliberate expansion from fixed literary examples to local experiments on the writer's own text.

### What's new
- Select a short, single-line phrase and preview **Echo**, **Isolate**, or **Omit**.
- Inspect the proposed full poem before an explicit Apply action.
- Undo the last experiment while its resulting text has not been edited.
- Refuse stale selections and previews using exact editor snapshots and Unicode-safe boundaries.
- Retain explicit saves, local-only operation, and compatibility with the existing collection.

### Quality and boundaries
The new workbench is deterministic and sends no poems to remote inference services. Browser tests verify selection, previews, guarded application, undo, and storage invariants. Technical verification does not establish that an intervention improves poetry.
