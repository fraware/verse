# Verse v0.3.0: Community-Ready Release

This release consolidates the private writing experience, the craft workbench, research transparency, and public-project documentation.

### Highlights
- A separate, voluntary `/study` instrument for evaluating revision workflows, with in-memory categorical responses and explicit, poem-free JSON export.
- A documented exploratory usability protocol and a strict offline descriptive analysis tool. **No participant study or efficacy result is claimed.**
- An [MIT License](https://github.com/fraware/verse/blob/main/LICENSE) for project source and documentation, subject to third-party notices.
- A restrained README masthead displaying only the shared Verse logo and title.
- Automated quality, accessibility, data-integrity, privacy, and Chromium/Firefox/WebKit release checks.
- A curated list of accessible community contribution opportunities in GitHub Issues.

### Before using Verse
Your work is stored in your browser profile's IndexedDB, not backed up to a cloud account. Export JSON backups from **My Collection** and store them safely. Shared browser profiles are not isolated from one another.

This release was built from the **exact green main-branch commit** that triggered the release workflow. The attached ZIP is a GitHub Pages static-site bundle targeting `/verse/`; GitHub provides the corresponding source archive.
