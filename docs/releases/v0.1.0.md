# Verse v0.1.0: Private Writing Foundation

The first verified Verse milestone establishes a free, browser-local place to write and keep poetry.

### Included in this snapshot
- Browser-local writing and a personal collection backed by transactional IndexedDB.
- Explicit saves, backup JSON export/import, and defensive handling of cross-tab edits.
- Protection against losing unsaved changes during navigation and save operations.
- A fixed catalogue of editorial examples across twelve poetic influences, plus general craft exercises.
- A static GitHub Pages deployment with browser privacy, accessibility, and functional regression checks.

### Important limits
Poems belong to the current browser profile, not an online account. Clearing browser data or losing the device can destroy writing. Export backups regularly. Literary examples are editorial illustrations, not AI analysis or guarantees of poetic quality.
